Для запуска полноценного веб-интерфейса выполните следующие действия в терминале:
>pip install streamlit pandas matplotlib

Сохраните код выше в файл app.py (в ту же директорию, где находится скрипт предсказателя и файл базы данных) и выполните команду:
> streamlit run architecture_dashboard.py
>
> После выполнения команды в консоли появится локальная ссылка (по умолчанию http://localhost:8501), открыв которую вы получите доступ к полноценной интерактивной интеракции с математической моделью.
