Для запуска полноценного веб-интерфейса выполните следующие действия в терминале:
>pip install streamlit pandas matplotlib

Сохраните код выше в файл app.py (в ту же директорию, где находится скрипт предсказателя и файл базы данных) и выполните команду:
> streamlit run architecture_dashboard.py
>
> После выполнения команды в консоли появится локальная ссылка (по умолчанию http://localhost:8501), открыв которую вы получите доступ к полноценной интерактивной интеракции с математической моделью.

Для отрисовки графиков и отправки сообщений скрипту требуются библиотеки matplotlib и requests. Установите их командой:
> pip install matplotlib requests.


Логика работы Telegram-бота и условия срабатывания
Уведомления отправляются не на каждый чих, а строго при соблюдении двух условий (Защита от спама):

>Смена вердикта — Итоговый статус (final_verdict) изменился (например, с Moderately Probable на Highly Probable).
>Фактор триггера — Изменение произошло по причине динамики объемов на Binance (скрипт парсит лог причины изменения).
